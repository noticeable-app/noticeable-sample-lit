# Noticeable Lit Sample

This project shows how to integrate Noticeable Widgets in a [Lit](https://lit.dev/) Web app.

The repository's commit history walks through the integration step by step:
https://github.com/noticeable-app/noticeable-sample-lit/commits/main

## Stack

- Lit 3
- @lit-labs/router
- Vite 8
- TypeScript

## Run locally

```sh
npm install
npm run dev
```

Then open `http://localhost:8000/`.
